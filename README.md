# aa-map-tiles

Builds the basemap archive (PMTiles, OpenMapTiles schema) for map.all-active.net with
[Planetiler](https://github.com/onthegomap/planetiler) from Geofabrik extracts of Germany,
Austria, Switzerland, Liechtenstein and Italy, and uploads it to Bunny storage under a new key.

Run: Actions -> Map Tiles -> Run workflow. Map data © OpenStreetMap contributors (ODbL).
